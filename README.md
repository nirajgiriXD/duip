# Profile Hunter

- CLI application for hunting user profile
- The application takes various arguments as input such as `username`, `email`, `phone`, etc.
- The apllication then searches for publicly available data on the internet that matchs best with the given arguments and presents it to the user

```
Note: This is only for educational purpose only 🗿
```

## Usage

- Download or clone the repository
- Run `npm i` to install required dependencies
- Run the app

```bash
node index.js --user=<user> --username=<username> --email=<email> --phone=<phone> --site=<site> --address=<address> --oraganization=<organization>
```
